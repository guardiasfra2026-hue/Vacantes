# Portal de Vacantes

MVP público construido con Next.js, React, TypeScript y Tailwind CSS.

## Probar localmente

```bash
npm install
npm run dev
```

Abre http://localhost:3000.

Incluye inicio, vacantes, detalle, vacantes por estado, recomendaciones, blog, formulario de postulación de demostración y panel administrativo inicial.

El siguiente paso para producción es conectar Supabase para guardar vacantes, postulaciones, noticias y proteger el panel admin.
